**Thesis Tracker**

*Autora: Florencia Nuñez C*

El programa nació de mi necesidad de obtener un seguimiento propio para sentir que estaba realizando progresos en mi tesis.

Thesis Tracker (versión básica) va a poder leer documentos y comparar las métricas entre diferentes versiones
- conteo de palabras, páginas, figuras, tablas totales
- conteo de palabras, párrafos, figuras, tablas por cada capítulo/sección del documento
- cambios en cada métrica con respecto a la versión previa
- historial de versiones
- progreso
- porcentaje de cambio de cada sección
- tiempo desde modificaciones nuevas a la sección
